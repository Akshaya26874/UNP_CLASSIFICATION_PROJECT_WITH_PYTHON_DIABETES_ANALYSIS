# UNP_CLASSIFICATION_PROJECT_WITH_PYTHON_DIABETES_ANALYSIS
This repository contains all materials related to a project that analyzes a diabetes dataset and builds machine learning models to predict whether a person is diabetic using features such as glucose, BMI, insulin, and age.PowerPoint presentation summarizing the project methodology, results, and findings.Python code for data exploration, cleaning, visualization, and classification model implementation.Documentation and notes on model performance evaluation.The project demonstrates how predictive models can assist in early diagnosis and improved healthcare planning.
